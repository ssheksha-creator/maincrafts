# MainCrafts Technology - Task 1

A modern and responsive landing page created using HTML5 and CSS3 as part of the Web Development Internship Task 1 assigned by MainCrafts Technology.

---

## 🚀 Project Overview

This project is a professional one-page landing website designed with:
- Modern UI/UX
- Responsive Layout
- Hero Section
- Feature Cards
- Footer Section
- Smooth Hover Effects
- Glassmorphism Design

The landing page is fully responsive and works across:
- Desktop
- Tablet
- Mobile Devices

---

## 🛠️ Technologies Used

- Google Fonts
- Font Awesome Icons
