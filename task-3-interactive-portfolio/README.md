# Interactive Portfolio Website

A modern and responsive portfolio website built using HTML, CSS, and JavaScript as part of MainCrafts Web Development Internship – Task 3.

## 🚀 Project Overview

This project extends the personal portfolio website by adding interactive JavaScript features such as:

* Dynamic Navigation Bar
* Active Menu Highlighting
* Contact Form Validation
* Dark Mode Toggle
* Local Storage Theme Persistence
* Responsive Design
* CSS Animations & Transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Google Fonts
* Font Awesome

## ✨ Features

### Dynamic Navbar

* Changes appearance while scrolling
* Highlights active navigation links

### Contact Form Validation

* Name validation
* Email format validation
* Message validation
* Inline error messages

### Dark Mode Toggle

* Switch between dark and light themes
* Theme preference saved using LocalStorage

### Responsive Design

* Mobile-friendly layout
* Tablet support
* Desktop optimization

### Modern UI Enhancements

* Glassmorphism effects
* Hover animations
* Smooth transitions
* Interactive project cards
